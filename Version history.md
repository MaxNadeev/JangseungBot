# v.0

## v.0.0

- **v.0.0.0** — Бот на node-telegram-bot-api: polling, логирование, JSON-список триггеров — чтобы модерировать группу по запрещённым словам.

- **v.0.0.1** — Уведомления админу о новых участниках и ошибках polling + Logger/JsonManager и отчёты с хэштегами — чтобы видеть происходящее в группе, не открывая чат.

## v.0.1

- **v.0.1.0** — Переход на GramJS (MTProto): `index.js` запускает режимы `--bot` (бот по токену) и `--client` (юзер-аккаунт) — чтобы получить и Bot API, и полный MTProto-доступ.

- **v.0.1.1** — Перенос данных в SQLite (better-sqlite3): таблицы users/restricted/admins и их права — чтобы хранить состояние участников локально.

- **v.0.1.2** — Получение состава группы (участники/баны/кики/админы) через юзер-клиент — чтобы синхронизировать группу в БД.

- **v.0.1.3** — Подсчёт сообщений на участника через `messages.Search` (`count`) — чтобы оценивать активность и пропускать проверку «старожилов».

- **v.0.1.4** — Удаление спам-сообщений по триггерам (включая спам/рекламу от ботов) + кнопки «Ограничить»/«Доверять» админу — чтобы модерировать в один клик.

- **v.0.1.5** — Расширение фильтра: разрешённые слова, корейский язык, minLength/minMessages, расширенное приветствие — чтобы снизить ложные срабатывания.

# v.1

## v.1.0

- **v.1.0.0** — Добавил обработку личных сообщений (`UpdateNewMessage`, только для `ADMIN_ID`), чтобы команда `/hi` работала и в чате с админом, а не только в супергруппе (в группе `/hi` как и раньше доступна всем).

- **v.1.0.1** — Обновил схему БД (`firstJoin` INTEGER, поле `trusted`, таблица `userFlags`) и добавил резервную БД `profiles.db`: снимок `userProfiles` (realName/gender/place/nationality/age/trusted + `firstJoin`/`birthday` TEXT) + таблицы истории `usernames`/`firstNames`/`lastNames`/`phones` (`updatedOn` TEXT `toLocaleString('ru-ru')`) — чтобы хранить ручные данные независимо от автособираемой `users.db` и видеть смену ника/имени/телефона по одному telegram ID.

- **v.1.0.2** — Инкрементальный подсчёт сообщений (считаются только прошедшие проверку, не удалённые) + корректная обработка входов (`firstJoin` пишется в `users` и в `profiles`, фикс приветствия) — чтобы `msgCount` был актуальным и не учитывал удалённый спам.

- **v.1.0.3** — Белый список: кнопка «Доверять» помечает пользователя `trusted` (в `profiles` и в `users`), спам-проверка пропускает админов и доверенных; `setTrusted` обновляет `updatedOn`; исправлена коллизия `updatedOn` в `GET_USER_DATA` — чтобы доверенные не проверялись на спам.

- **v.1.0.4** — Автобан «молчащих» новичков: участник без единого сообщения через порог (настройка в `triggers.json`, по умолчанию 5 мин) получает лишение прав + отчёт админу с кнопками «Разбан»/«Доверять»; админы и доверенные исключены; добавлен планировщик `Scheduler` — чтобы отсекать спам-аккаунты автоматически.

- **v.1.0.5** — Исправил inline-кнопки в отчётах админу: в GramJS ключ называется `buttons`, а не `replyMarkup`, поэтому кнопки раньше не прикреплялись — чтобы кнопки «Ограничить»/«Доверять»/«Разбан» снова работали.

- **v.1.0.6** — Запрет фото/видео для новичков: первые N сообщений (`minMessagesForMedia` в `triggers.json`, по умолчанию 5) не могут содержать фото/видео — при нарушении сообщение удаляется и админ получает отчёт с кнопками.

- **v.1.0.7** — `--client`: кик удалённых (заблокированных Telegram) аккаунтов и заполнение `firstJoin` (дата входа из `result.participants`) — чтобы чистить «мёртвые» аккаунты и знать, с какого числа пользователь в группе.

- **v.1.0.8** — Исправил данные ограничений в `restricted`: `restrictionDate`/`untilDate` теперь корректные ru-ru строки (было «Invalid Date» и 1970 год из-за путаницы секунд/миллисекунд), `untilDate` в схеме TEXT, `restrictedBy` заполняется id `--client`, а кикнутые получают `isInGroup=0`/`isKicked=1` — чтобы блокировки хранились корректно.

- **v.1.0.9** — `firstJoin` в `users` теперь ru-ru строка (конвертация epoch↔строка через `parseRuDate`), а правило «молчунов» ограничено окном `silentJoinWindowMin` (по умолчанию 60 мин) — чтобы не банить давно молчащих «старожилов», а только свежих новичков.

- **v.1.0.10** — Перевёл все даты в БД на ISO-8601 (`гггг-мм-дд чч:мм:сс`) через `formatIso` — строки стали сортируемыми в SQL (`ORDER BY`/сравнение корректны), читабельность сохранена; `parseRuDate` удалён, сравнение `firstJoin` вернулось в SQL.
